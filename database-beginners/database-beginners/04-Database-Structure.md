# 04 — Database Structure & Table

## Database Structure
একটি Database-এর ভিতরে একাধিক **Table** থাকতে পারে।

```text
Database
├── Table 1
│   └── Data
└── Table 2
    └── Data
```

## Table কী?
Table হলো row ও column-এর মাধ্যমে data সংরক্ষণের একটি structure।

### উদাহরণ: Student Table

| RollNo | Name | Class | DOB | Gender | City | Marks |
|---:|---|---|---|---|---|---:|
| 1 | Nanda | X | 1995-06-06 | M | Agra | 551 |
| 2 | Saurabh | XII | 1993-05-07 | M | Mumbai | 462 |

## গুরুত্বপূর্ণ Terms
- **Row** — একটি record
- **Column** — একটি field/attribute
- **Table** — records-এর structured collection
