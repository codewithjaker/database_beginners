# 01 — Database & DBMS

## শিখব কী?
- Database কী
- DBMS কী
- Database ও DBMS-এর সম্পর্ক

## Database কী?
Database হলো এমন একটি **collection of data** যা এমনভাবে সংরক্ষণ করা হয় যাতে data সহজে access করা যায়।

সহজভাবে: অনেক তথ্যকে একটি organized digital format-এ সংরক্ষণ করার ব্যবস্থাই Database।

## DBMS কী?
**DBMS (Database Management System)** হলো Database manage করার জন্য ব্যবহৃত software application।

## গুরুত্বপূর্ণ বিষয়
- Database = Data-এর organized collection
- DBMS = Database manage করার software

## উদাহরণ
Student information, customer information, product information ইত্যাদি Database-এ রাখা যায়।

## Practice
1. Database-এর সংজ্ঞা লিখুন।
2. DBMS-এর পূর্ণরূপ লিখুন।
3. Database ও DBMS-এর মধ্যে পার্থক্য লিখুন।
