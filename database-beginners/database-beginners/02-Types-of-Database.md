# 02 — Types of Database

## Database-এর প্রধান ধরন

### 1. Relational Database
Relational Database-এ data **tables** আকারে সংরক্ষণ করা হয়।

উদাহরণ:
- MySQL
- Microsoft SQL Server
- Oracle
- PostgreSQL

### 2. Non-relational Database (NoSQL)
Non-relational Database-এ data traditional table structure-এ সংরক্ষণ করা হয় না।

উদাহরণ:
- MongoDB

## SQL কোথায় ব্যবহার করি?
PDF অনুযায়ী, **Relational DBMS-এর সাথে SQL ব্যবহার করা হয়।**

## সহজভাবে
| Type | Data Structure |
|---|---|
| Relational | Tables |
| Non-relational / NoSQL | Traditional tables নয় |
