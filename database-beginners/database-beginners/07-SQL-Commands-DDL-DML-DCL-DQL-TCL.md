# 07 — Types of SQL Commands

## 1. DDL — Data Definition Language
Database/table structure define বা change করতে ব্যবহৃত হয়।

Commands:
- `CREATE`
- `ALTER`
- `RENAME`
- `TRUNCATE`
- `DROP`

## 2. DML — Data Manipulation Language
Data manipulate করতে ব্যবহৃত হয়।

Commands:
- `SELECT`
- `INSERT`
- `UPDATE`
- `DELETE`

## 3. DCL — Data Control Language
User permission control করতে ব্যবহৃত হয়।

- `GRANT`
- `REVOKE`

## 4. DQL — Data Query Language
- `SELECT`

## 5. TCL — Transaction Control Language
- `START TRANSACTION`
- `COMMIT`
- `ROLLBACK`

## Practice
1. DDL-এর ৫টি command লিখুন।
2. DML-এর commandগুলো লিখুন।
3. DCL কেন ব্যবহৃত হয়?
4. TCL-এর দুটি command লিখুন।
