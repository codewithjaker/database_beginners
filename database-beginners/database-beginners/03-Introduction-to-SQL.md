# 03 — Introduction to SQL

## SQL কী?
**SQL = Structured Query Language**

SQL হলো relational database-এর সাথে interact করার জন্য ব্যবহৃত programming language।

## CRUD Operations
SQL দিয়ে মূলত CRUD operations করা হয়:

- **Create** — data/resource তৈরি করা
- **Read** — data পড়া
- **Update** — data পরিবর্তন করা
- **Delete** — data মুছে ফেলা

## গুরুত্বপূর্ণ ধারণা
SQL-এর মাধ্যমে relational database-এর data এবং database structure নিয়ে কাজ করা যায়।
