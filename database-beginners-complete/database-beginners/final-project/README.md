# Final Project — Student Management Database

## লক্ষ্য
একটি practical Student Management Database তৈরি করা এবং course-এর প্রধান SQL concepts প্রয়োগ করা।

## Tables

- `course`
- `city`

## Project Tasks
1. Database তৈরি করুন।
2. Tables তৈরি করুন।
3. Sample data insert করুন।
4. সব data select করুন।
5. Marks-এর ভিত্তিতে filter করুন।
6. City-wise student count করুন।
7. City-wise average marks বের করুন।
8. Maximum marks 90-এর বেশি city group করুন।
9. Student + Course + City JOIN করুন।
10. Class average-এর চেয়ে বেশি marks-এর student বের করুন।
11. একটি View তৈরি করুন।
12. একটি UNION query লিখুন।
13. একটি update operation করুন।
14. একটি safe delete operation লিখুন।
15. Final report query তৈরি করুন।

## Completion Criteria
শিক্ষার্থী নিজে SQL script লিখে database তৈরি, data manipulation, analysis এবং multi-table query চালাতে পারলে project সম্পন্ন।
