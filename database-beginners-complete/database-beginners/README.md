# Database Beginners — Complete SQL Course Package

## Course Basis
এই package-এর lesson content মূলত user-provided `SQL (notes).pdf`-এর ৫৯ পৃষ্ঠার বিষয়গুলো অনুসরণ করে তৈরি করা হয়েছে। Practice, exercise, solution, quiz এবং final project অংশগুলো course-টিকে hands-on করার জন্য সাজানো extension।

## Folder Structure

```text
database-beginners/
├── README.md
├── lessons/          # 24 Bangla + English SQL lessons
├── exercises/        # 24 lesson-wise exercises
├── solutions/        # 24 solution guides
├── sql-practice/     # Ready-to-run MySQL practice scripts
├── quizzes/          # Module-wise quizzes
└── final-project/    # Student Management Database
```

## How to Use

### Step 1
`lessons/` থেকে ধারাবাহিকভাবে পড়ুন।

### Step 2
প্রতিটি lesson-এর একই নম্বরের file `exercises/` থেকে solve করুন।

### Step 3
তারপর `solutions/` দিয়ে answer check করুন।

### Step 4
`sql-practice/`-এর SQL scripts MySQL environment-এ run করুন।

### Step 5
`quizzes/` দিয়ে module assessment নিন।

### Step 6
সবশেষে `final-project/` সম্পন্ন করুন।

## Recommended Environment
MySQL-compatible SQL environment ব্যবহার করুন।

## Important
SQL destructive command (`DROP`, `DELETE`, `TRUNCATE`) production data-তে চালানোর আগে অবশ্যই সতর্ক থাকুন।
