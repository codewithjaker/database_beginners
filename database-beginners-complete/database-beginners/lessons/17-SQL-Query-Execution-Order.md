# Lesson 17 — SQL Query General Order

```sql
SELECT column(s)
FROM table_name
WHERE condition
GROUP BY column(s)
HAVING condition
ORDER BY column(s) ASC;
```

## General Structure
1. SELECT
2. FROM
3. WHERE
4. GROUP BY
5. HAVING
6. ORDER BY

## Practice
একটি query লিখুন যেখানে WHERE + GROUP BY + HAVING + ORDER BY থাকবে।
