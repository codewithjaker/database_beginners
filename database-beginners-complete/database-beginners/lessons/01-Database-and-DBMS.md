# Lesson 01 — Database & DBMS

## শিখব কী?
- Database কী
- DBMS কী
- Database ও DBMS-এর সম্পর্ক

## Database কী?
Database হলো এমন একটি collection of data যা সহজে access করা যায় এমন digital format-এ রাখা হয়।

## DBMS কী?
**DBMS (Database Management System)** হলো Database manage করার software application।

## সহজভাবে
- Database → organized data
- DBMS → database manage করার software

## Practice
1. Database-এর সংজ্ঞা লিখুন।
2. DBMS-এর পূর্ণরূপ লিখুন।
3. Database ও DBMS-এর পার্থক্য লিখুন।
