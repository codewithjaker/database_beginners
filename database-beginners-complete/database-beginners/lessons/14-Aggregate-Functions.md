# Lesson 14 — Aggregate Functions

Aggregate functions multiple values-এর উপর calculation করে single value return করে।

- `COUNT()`
- `MAX()`
- `MIN()`
- `SUM()`
- `AVG()`

```sql
SELECT COUNT(name) FROM student;
SELECT MAX(marks) FROM student;
SELECT MIN(marks) FROM student;
SELECT SUM(marks) FROM student;
SELECT AVG(marks) FROM student;
```

## Practice
Student table থেকে count, max, min, sum ও average বের করুন।
