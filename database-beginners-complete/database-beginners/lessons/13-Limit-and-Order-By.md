# Lesson 13 — LIMIT & ORDER BY

## LIMIT

```sql
SELECT * FROM student LIMIT 3;
```

## ORDER BY

```sql
SELECT * FROM student ORDER BY city ASC;
SELECT * FROM student ORDER BY marks DESC;
```

- `ASC` = ascending
- `DESC` = descending
