# Lesson 02 — Types of Database

## Relational Database
Data table-এর মধ্যে store করা হয়।

Examples:
- MySQL
- SQL Server
- Oracle
- PostgreSQL

## Non-relational Database (NoSQL)
Traditional table structure-এ data store করা হয় না।

Example:
- MongoDB

## গুরুত্বপূর্ণ
Relational DBMS-এর সাথে SQL ব্যবহার করা হয়।
