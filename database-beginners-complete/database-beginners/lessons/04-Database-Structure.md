# Lesson 04 — Database Structure & Table

## Database Structure

```text
Database
├── Table 1
│   └── Data
└── Table 2
    └── Data
```

## Table কী?
Table হলো rows ও columns-এর মাধ্যমে data রাখার structure।

### Example

| RollNo | Name | Class | City | Marks |
|---:|---|---|---|---:|
| 1 | Nanda | X | Agra | 551 |
| 2 | Saurabh | XII | Mumbai | 462 |

- Row = record
- Column = field/attribute
- Table = structured collection of records
