DATABASE PROJECTS
=================

01-student-management-system.sql
Student, teacher, course, enrollment, result and payment management.

02-ecommerce-management-system.sql
Category, supplier, product, customer, order, order item and payment management.

03-clinic-hospital-management-system.sql
Department, doctor, patient, appointment, medicine, prescription and billing management.

These projects practice the Database Beginners syllabus: CREATE/DROP, tables, data types,
Primary Key, Foreign Key, constraints, INSERT, SELECT, UPDATE, DELETE, WHERE, operators,
LIMIT, ORDER BY, aggregate functions, GROUP BY, HAVING, JOIN, UNION, subquery and Views.
Run each SQL file separately in a MySQL-compatible environment.
